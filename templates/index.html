Connection

Valida la conectividad de red en tiempo real: prueba puertos TCP (equivalente a telnet), resuelve DNS, inspecciona el certificado TLS de un host y lanza peticiones HTTP completas (método, headers, cuerpo y tiempo de respuesta, como un curl).

Abrir Connection → GET / POST · /base64

Base64

Codifica texto a Base64 o decodifícalo de vuelta a texto plano. Pensado para revisar rápido tokens, payloads o variables de entorno codificadas sin salir del navegador.

Abrir Base64 → GET / POST · /cert

Certificados

Pega un certificado PEM completo (con su cadena) y obtén su versión en una sola línea, lista para pegar en un Secret, una variable de entorno o un comando jq -n, además de su equivalente en Base64.

Abrir Certificados → GET / POST · /resources
